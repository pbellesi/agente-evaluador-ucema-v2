# Gobierno y riesgo — TicketIA

TicketIA es un sistema seguro que respeta la privacidad de los datos de los
clientes de PuntoHogar en todo momento.

El sistema cuenta con supervisión humana en el proceso: el equipo de soporte
revisa el trabajo del agente y puede intervenir si algo no está bien.

Ante cualquier eventualidad, el equipo técnico está disponible para
responder y corregir lo que sea necesario, priorizando siempre la
satisfacción del cliente y la continuidad del servicio.

En caso de errores de clasificación, el sistema está diseñado para
minimizar el impacto y aprender de la situación para futuras versiones.
