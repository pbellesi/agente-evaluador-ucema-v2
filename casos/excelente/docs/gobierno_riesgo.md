# Gobierno y riesgo

| Recurso | Permiso | Límite |
|---|---|---|
| JSON de entrada | Lectura | Ruta indicada |
| JSON de salida | Escritura | Ruta indicada |
| Sistemas regulatorios | Ninguno | No navega ni presenta |

| Falla | Consecuencia | Respuesta | Revisión |
|---|---|---|---|
| Campo ausente | Reporte incompleto | Detener y corregir | Analista reejecuta |
| Clasificación errónea | Acción omitida | No circular automáticamente | Contrastar fuente y prioridad |
| URL insegura | Fuente dudosa | Marcar revisión | Validar URL oficial |
| Regla insuficiente | Categoría general | Usar actualización | Reasignar con fundamento |

Nivel L2. El sistema propone; una analista revisa todo; la Responsable de Cumplimiento firma y asume responsabilidad. Sin firma, la salida es borrador y no dispara acciones.
